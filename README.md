# Sink ’Em — Battleship

A one-player Battleship game built with the Next.js App Router. Place your own fleet before the battle; the computer fleet is placed automatically and kept hidden.

## Run locally

```sh
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Drag ships from the fleet list onto your board, or select a ship and click a starting square. Drag placed ships by any block to move them, or click an end block to rotate around it. You can also use **Random Placement** and adjust the result. Then choose a square on the enemy board to fire. The computer replies after a short delay, and **New Battle** returns to fleet deployment.
